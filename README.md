# Мобильное расписание ВУЗа
Для обновления скрапера поместить ветку scrapper в ...\SSU_ScheduleApp\mail\scrapper


## Стек: Docker, postgress, go, Kafka+UI, grpc+rest.

Сборщик для linux,mac,windows.
В сборщике для линукс sh файл нужно сделать исполняемым.

## Готовый бек
При вашем желании, фронтенд на flutter dart, можете заменить на свой, сервер отдает на порты 8082gRPC и 8081rest.

Для работы некоторых факультетов, следует парсить "РАСПИСАНИЕ СЕССИИ", в некоторых заочных группах расписание пишется там. С реализацией парсинга сессии, получится реализовать расписание сессии для всех групп.
Схему бд можно посмотреть при подключении postgress. Логин и пасс свободно меняются в mail и не забудьте в Docker сменить.

### Возможности для улучшения.
-реализовать .env, для хранения логин пасс для бд.
-реализовать расписание сессии.
-реализовать заметки в облаке.
